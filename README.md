# APEQ MARKET PLACE 🛍️

A full-stack e-commerce web application built with Streamlit and SQLite.

## Features
- Product Catalog & Cart
- Payment After Delivery Order Flow
- Real-time GPS Location Capture via Google Maps
- Order Receipt Generation & Download
- Admin Portal for Product and Order Management

## Setup & Run
```bash
pip install -r requirements.txt
streamlit run apeqgeneralstores.py
